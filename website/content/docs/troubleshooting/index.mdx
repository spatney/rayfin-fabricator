Use this page when Fabricator gets stuck, a sign-in fails, a preview is blank, or a deploy does not finish. Start with the checks below, then use the symptom index.

## Ask Help first

Fabricator has a built-in assistant that reads the errors it recorded on your computer and explains what went wrong.

1. In the status bar, select **Help**, or press `Ctrl+J` (`Cmd+J` on macOS).
2. Describe the problem, such as "why did my last deploy fail?".

Help often identifies the cause faster than working through the index below, because it can see the exact error you hit. See [Ask Help](/docs/troubleshooting/help).

## First steps for any problem

1. Update to the latest version. Restart Fabricator so it checks for an update, and install the update if Fabricator offers one. If you installed an old build from before auto-update existed, download and install the latest release once from [GitHub Releases](https://github.com/spatney/rayfin-fabricator/releases/latest). Future updates are in-app.
2. Restart Fabricator. This refreshes the bundled Copilot engine, PATH discovery, the preview surface, and any setup checks that depend on tools installed while the app was open.
3. Re-check setup. On the setup screen, select **Re-check** after installing Node.js, Git, Azure CLI, GitHub CLI, or after signing in.
4. Check the status bar version. The lower-right status bar shows the Fabricator app version. Include that version in reports.
5. Read the exact message. The fastest fix usually depends on the exact quoted error in the banner, modal, chat card, or setup row.

## Get help

If the fix for your symptom does not work, collect diagnostics and open a report:

1. In the status bar, select **Help**.
2. Describe the problem, or ask Help to report it for you.
3. Select **Report this on GitHub**, then drag the diagnostics file that Fabricator created onto the issue.

See [Report a problem](/docs/troubleshooting/report-a-problem) for what Fabricator includes and what to remove before posting publicly.
