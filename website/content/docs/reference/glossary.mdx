title: "Glossary"
description: "Plain-language definitions of the terms used in Fabricator and these docs, from Rayfin and Fabric capacity to working copies and deploy identities."
---

## Advisor

The health dashboard for a Rayfin app. It runs quick checks locally and can run a read-only Copilot deep review. See [Advisor](/docs/ship/advisor).

## App identity

The identity a Rayfin app's connections use when they're set to application access: the owner of the app's Fabric item. For your own apps, that's the Fabric account that first published the app; for team apps, the team's deploy identity. While your app runs on this computer with the [Local development](/docs/reference/glossary#local-development) experiment, these connections run as you instead. Blueprint shows which connections use it. See [Blueprint](/docs/build/data-model#whose-credentials-the-app-identity-uses).

## App item

A Fabric item created when you publish a Rayfin app. Fabricator may also call this a Fabric app or App item when describing published apps. See [Publish to Microsoft Fabric](/docs/ship/deploy).

## Autopilot

A chat route used after an approved plan when Copilot continues autonomously end to end. See [Chat](/docs/build/chat).

## Azure CLI

Microsoft's command-line tool for Azure. Signing in to it is optional. Fabricator uses it to find people when you share an app, add Fabric data, read the Power BI reports you migrate, and set up team workspaces. While your app runs on this computer with the [Local development](/docs/reference/glossary#local-development) experiment, its functions and connectors use the Azure CLI's account too. See [Manage your accounts](/docs/start/accounts) and [Migrate a Power BI report](/docs/build/migrate-power-bi).

## Build permission

A Power BI permission on a semantic model that lets someone query it. An app that reads a semantic model as each person who uses it, such as a migrated Power BI report, needs everyone who uses it to have Build permission. Sharing an app grants it on the semantic models the app reads from other workspaces. See [Share your app](/docs/ship/share).

## Capacity

Fabric capacity is the compute capacity assigned to Fabric workspaces. To publish a Rayfin app, you need a workspace on a Fabric (F-SKU) or Power BI Premium (P-SKU) capacity. Fabricator publishes a new app before you build it with chat, so you need one to build too, unless the [Local development](/docs/reference/glossary#local-development) experiment is on. Team workspace setup asks you to choose a capacity. See [Publish to Microsoft Fabric](/docs/ship/deploy) and [Team prerequisites](/docs/team/prerequisites).

## Community example

A ready-made Rayfin app template from the awesome-rayfin gallery or another template URL. Use **Start from a community example** when creating a project. See [Projects](/docs/build/projects).

## Deep review

A read-only Copilot review started from the Advisor with **Run deep review**. It checks issues that need judgment and cannot edit files or run commands. See [Advisor](/docs/ship/advisor).

## Deploy identity

A Microsoft Entra ID service principal used by a team workspace pipeline to deploy apps to Fabric. Team apps never deploy from a member's computer. See [Team workspaces](/docs/team).

## Deployment

Rayfin's word for an app in a Fabric workspace, put there with `rayfin up`. Fabricator calls it a [published app](/docs/reference/glossary#published-app). See [Publish to Microsoft Fabric](/docs/ship/deploy).

## Design mode

A preview mode where you select elements in the app, describe visual changes, and send those changes to Copilot. See [Design mode](/docs/build/design).

## Fabric app

A Rayfin app hosted in Microsoft Fabric. In Fabric, the published app is represented by Fabric items in a workspace. See [Publish to Microsoft Fabric](/docs/ship/deploy).

## Fabric brokered auth

How Rayfin apps sign people in: Fabric signs them in with the Microsoft Entra account they use for Fabric. The app needs no identity provider to run and no app registration of its own in Microsoft Entra ID, so there's nothing for a tenant admin to approve. Rayfin's docs also call it Fabric SSO. While your app runs on this computer with the [Local development](/docs/reference/glossary#local-development) experiment, a local Fabric sign-in page stands in for Fabric's. See [Blueprint](/docs/build/data-model#how-people-sign-in) and [Rayfin's auth docs](https://rayfin.ai/docs/auth).

## Fabric workspace

A Microsoft Fabric container for app items, data, semantic models, and other Fabric resources. You publish apps to one. See [Publish to Microsoft Fabric](/docs/ship/deploy).

## Finding

An Advisor issue. A finding includes what was flagged, why it matters, where it appears, and how to fix it. See [Advisor](/docs/ship/advisor).

## GitHub CLI

GitHub's `gh` command-line tool. Fabricator uses it for cloning and team workspace repository operations. See [System requirements](/docs/reference/requirements).

## Local backend

The backend that runs your app on this computer while you build it, with the [Local development](/docs/reference/glossary#local-development) experiment on: its data, sign-in, functions, connectors and storage, and the app's own dev server. It's [rayfin-local](/docs/reference/glossary#rayfin-local), which comes with Fabricator. Fabricator starts it when you open a personal project; team apps run on Fabric. See [How Fabricator works](/docs/reference/how-it-works#the-local-backend).

## Local data

The data your app stores while it runs on this computer with the [Local development](/docs/reference/glossary#local-development) experiment: its records, local users and stored files. It starts empty, stays in the project's `.rayfin-local` folder, and is separate from your published app's data. See [Files and folders](/docs/reference/files#your-apps-local-data).

## Local development

An experiment, off by default, that runs your apps and their backend on this computer while you build, and lets you publish to Microsoft Fabric when you choose. With it on, a new app opens with chat ready, without a publish step. Turn it on in **Settings → Experiments**. See [Develop on this computer](/docs/build/local-development).

## Microsoft Entra ID

Microsoft's identity platform. People sign in to Rayfin apps with their Microsoft Entra account, through [Fabric brokered auth](/docs/reference/glossary#fabric-brokered-auth). Team workspace deploy identities are service principals in Microsoft Entra ID. See [Team prerequisites](/docs/team/prerequisites).

## Microsoft Fabric

Microsoft's data and analytics platform where Rayfin apps are published and hosted. See [Publish to Microsoft Fabric](/docs/ship/deploy).

## Personal preview

A team workspace preview deployed for one member's working branch. See [Work on an app](/docs/team/work-on-an-app).

## Pipeline

The GitHub workflow in a team workspace repository that deploys previews and published apps to Fabric. See [Team workspaces](/docs/team).

## Preview

The pane that shows your app inside Fabricator. It shows your published app and, while Copilot works, the app's pages from this computer with the published app's backend. With the [Local development](/docs/reference/glossary#local-development) experiment on, it shows the app running on this computer, or its published copy in Fabric. For team apps, it shows the app against the team's preview in Fabric. See [Live preview](/docs/build/preview).

## Preview as

A menu in the preview's toolbar, with the [Local development](/docs/reference/glossary#local-development) experiment on, that chooses who your app on this computer signs in as: you, a test user you add, or no one. See [Preview as someone else](/docs/build/preview#preview-as-someone-else).

## Publish

Put your app in a Fabric workspace, with `rayfin up`, so other people can use it. Select **Publish** in the app bar. A new app is published before you build it with chat, unless the [Local development](/docs/reference/glossary#local-development) experiment is on. **Publish after each chat turn** publishes your changes after every successful turn: it's on by default, and off by default with Local development on. Fabricator used to call this deploying. See [Publish to Microsoft Fabric](/docs/ship/deploy).

## Published app

Your app's copy in a Fabric workspace, which the people you share it with use. It keeps its data in Fabric, and an app can be published to more than one workspace. With the [Local development](/docs/reference/glossary#local-development) experiment on, its data is separate from the [local data](/docs/reference/glossary#local-data) on this computer. For a team app, the published app is the shared version deployed from the repository's main branch. See [Publish to Microsoft Fabric](/docs/ship/deploy) and [Publish changes](/docs/team/publish).

## Quick check

An Advisor rule that runs locally without Copilot. Quick checks re-run as the project changes. See [Advisor](/docs/ship/advisor).

## Rayfin

Microsoft's platform for building apps whose backend runs on Microsoft Fabric. Fabricator builds Rayfin apps and publishes them to Fabric. With the [Local development](/docs/reference/glossary#local-development) experiment on, it runs them on this computer while you build them. See [Rayfin's docs](https://rayfin.ai).

## Rayfin CLI

The command-line tool Fabricator runs through `npx rayfin` from each project. It publishes apps and manages Fabric sign-in. See [Rayfin versions](/docs/ship/rayfin-versions).

## rayfin-local

A local Rayfin backend that Fabricator bundles to run your app on this computer when the [Local development](/docs/reference/glossary#local-development) experiment is on. It answers the same requests as the app's backend in Fabric, so the app runs unchanged. See [Local backend](/docs/reference/glossary#local-backend) and the [rayfin-local repository](https://github.com/spatney/rayfin-local).

## Secret

A value such as an API key or password that your app's Rayfin functions read on the server. Its value is stored with the published app. With the [Local development](/docs/reference/glossary#local-development) experiment on, your app also keeps a value on this computer. Neither value is shown again. See [Secrets](/docs/build/secrets).

## Semantic model

A Fabric or Power BI model that describes tables, columns, measures, and relationships for analytical data. Fabricator can help connect an app to a semantic model. See [Blueprint](/docs/build/data-model).

## Skill

Reusable instructions or tools that guide the Copilot agent for a specific kind of Rayfin work. See [Skills](/docs/build/skills).

## Team workspace

An experimental shared workspace backed by a private GitHub repository, Fabric workspaces, deploy identities, and a pipeline. See [Team workspaces](/docs/team).


## Turn

One request-and-response cycle in chat. A turn can include tool calls, file edits, diffs, and a work log. See [Chat](/docs/build/chat).

## Universal App

The default template that comes with the Rayfin CLI, used for new projects. It starts small, with no database, and grows into the app you describe in chat. See [Projects](/docs/build/projects).

## Work log

The live list of files read, searches, commands, output, and edits during a chat turn. See [Chat](/docs/build/chat).

## Working branch

The git branch Fabricator creates for your copy of a team app. It is where your changes live before publishing. See [Work on an app](/docs/team/work-on-an-app).

## Working copy

Your local or team-specific copy of an app while you work on changes. In team workspaces, each member works on their own copy before publishing. See [Work on an app](/docs/team/work-on-an-app).
