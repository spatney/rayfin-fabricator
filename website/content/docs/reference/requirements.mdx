Use this page to check whether your computer and accounts can run Fabricator, build Rayfin apps, and publish them to Microsoft Fabric.

## Operating systems

Fabricator supports:

- Windows 10 or Windows 11. The app uses WebView2 for its embedded browser surfaces.
- macOS on Apple Silicon. The bundle targets macOS 11.0 or newer.

The published macOS build is Apple Silicon (`aarch64`/arm64). The release workflow does not publish an Intel macOS installer.

## Required tools

Setup checks these tools:

| Tool | Required | Minimum | Setup behavior |
| --- | --- | --- | --- |
| Node.js | Yes | 22.12 | Can install with `winget` on Windows or Homebrew on macOS, or open the Node.js download page. |
| npm | Yes | Any installed version | Installed with Node.js. |
| Git | Yes | Any installed version | Can install with `winget` or Homebrew, or open the Git download page. |
| Azure CLI | No | Any installed version | Optional, for signing in to Azure. Can install with `winget` or Homebrew, or open the Azure CLI install page. |
| GitHub CLI (`gh`) | No | Any installed version | Optional repository browsing and cloning. |
| Local backend | No | Comes with Fabricator | Checks that rayfin-local, which runs your apps on this computer, can run. There's nothing to install. |

Fabricator bundles the Copilot engine it uses for chat. You do not need to install a separate Copilot CLI.

Fabricator also bundles rayfin-local, a local Rayfin backend. It runs your apps and their data on this computer while you build them, and runs your app's functions and dev server with Node.js. See [How Fabricator works](/docs/reference/how-it-works#the-local-backend).

Fabricator does not require a global Rayfin CLI for ordinary projects. It uses each project's locally installed Rayfin CLI and SDK. New projects start on the newest Rayfin release that rayfin-local runs. Learn more about Rayfin at [rayfin.ai/docs](https://rayfin.ai/docs).

## Accounts

You need:

- A GitHub account with GitHub Copilot access.
- For GitHub Enterprise Cloud with data residency, a `.ghe.com` Enterprise Cloud host. GitHub Enterprise Server is not supported by Fabricator's Copilot sign-in flow.
- Microsoft Fabric access, to publish apps. Your apps run on this computer while you build them, so you need it only when you publish.

These are optional, and Fabricator asks for them when a feature needs them:

- An Azure CLI sign-in, to share apps, add Fabric data, migrate Power BI reports and set up team workspaces. It also lets your app's functions and connectors use your Azure access while the app runs on this computer.

Fabric sign-in happens when Fabricator needs the project's Rayfin CLI to access Fabric, such as listing workspaces, publishing, sharing, or refreshing Fabric credentials. The app bar and the publish panel show **Sign in to Fabric** when needed.

## Fabric capacity

To publish a Rayfin app, you need a Fabric workspace on an eligible capacity:

- Fabric capacity, shown as **F-SKU**.
- Power BI Premium capacity, shown as **P-SKU**.

You don't need one to build an app: your apps run on this computer, and you need a capacity only when you publish.

Workspaces without an eligible capacity are listed as not eligible. If no eligible workspace is available, Fabricator offers **Start a free trial** and **Buy a capacity** links when you publish.

## Network access

Fabricator needs network access to the services it calls in the app:

- GitHub Releases for downloading and updating Fabricator.
- GitHub sign-in for Copilot, and GitHub APIs when using repository features.
- Tool download sites when setup opens an installer page.
- npm package feeds when creating or installing app projects.
- Azure CLI sign-in, when you sign in to Azure.
- Microsoft Fabric and Rayfin endpoints used by the project's Rayfin CLI when you publish.
- Power BI, and Fabric SQL databases and warehouses on TCP port 1433, when your app's connectors run on this computer.
- `https://rayfin.ai` when Advisor or Copilot follows Rayfin documentation links.

If your organization filters network traffic, allow the domains required by GitHub, npm, Azure CLI, Microsoft Fabric, and Rayfin for your tenant.

Your app's dev server listens only on this computer, on a `localhost` port such as 5173. So does the local backend that runs your app, on a port such as 7171.

## Optional tools

GitHub CLI (`gh`) is optional. Install it if you want Fabricator to browse or clone GitHub repositories from the app. It is separate from the bundled Copilot engine.

VS Code is optional. In the **Code** view, **Open in VS Code** opens the project folder when the `code` command is available. If it is not, Fabricator opens the folder in the operating system file manager instead.
