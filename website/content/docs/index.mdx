---
title: "What is Fabricator?"
description: "Fabricator is a desktop workbench for building Rayfin apps with Copilot. Apps run on your computer while you build them, and you publish them to Microsoft Fabric when you're ready."
---

Fabricator helps you build [Rayfin](https://rayfin.ai/docs) apps in one desktop window. You describe the app you want, watch GitHub Copilot build it, and try it as it changes: the app and its backend run on this computer from the moment you create it. When it's ready for other people, you publish it to Microsoft Fabric, and keep refining it from chat.

![The Fabricator workbench. On the left, the chat shows a finished Copilot turn that built an expense tracker; on the right, the preview shows the running app with a monthly total and a spending chart.](/screenshots/workbench.webp)

## The build loop

1. Create or open a project. Fabricator starts the app on this computer.
2. Describe the app in plain language.
3. Watch the work log while Copilot changes files and runs checks.
4. Try the app in the preview while Copilot works. Its data, sign-in and functions run on this computer too.
5. Refine the app with another prompt, a visual Design change, or an Advisor finding.
6. Publish the app to a Fabric workspace when you want other people to use it.

Rayfin is the app platform your project uses. While you build, Fabricator runs your app on rayfin-local, a local Rayfin backend that comes with Fabricator. The app's data starts empty and stays on this computer. When you publish, Fabricator runs the project's Rayfin tooling to put the app in Microsoft Fabric, where it's hosted and shared; see Rayfin's [Fabric app deploy docs](https://rayfin.ai/docs/deploy/fabric-apps) for the platform background, and [How Fabricator works](/docs/reference/how-it-works) for the details.

## Who Fabricator is for

Fabricator is for people who want to make Rayfin apps without living in a terminal. It can help if you are:

- Trying Rayfin for the first time.
- Turning a business workflow into a small app.
- Iterating on a data model or UI with Copilot, and publishing it to Fabric.
- Reviewing generated code, history, and app health in one place.

You do not need to pick a template for a new app. **New project** asks for a name, creates the app from the Rayfin CLI's default Universal App template, and opens it with chat ready. The app runs on this computer right away, so you don't need a Fabric workspace until you publish it.

## What you need

Before you start, check the [system requirements](/docs/reference/requirements). In short, you need:

- Windows 10/11, or macOS on Apple Silicon.
- Node.js 22.12 or newer, npm, and Git.
- A GitHub Copilot account.
- Optional: the Azure CLI, to share apps, add Fabric data and migrate Power BI reports. You can sign in to it later.
- To publish: Microsoft Fabric access and a Fabric workspace on an eligible Fabric or Power BI Premium capacity.
- Optional GitHub CLI (`gh`) for repository browsing and cloning.
