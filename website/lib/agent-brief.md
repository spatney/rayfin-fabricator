# Fabricator — instructions for coding agents

Fabricator is a desktop app, not an API. It helps people build Rayfin apps by chatting with GitHub Copilot, previewing the app live, and deploying it to Microsoft Fabric.

## Use these docs

- Every docs route has a Markdown mirror: append `.md` to the URL.
- Start troubleshooting at `/docs/troubleshooting`.
- For Rayfin SDK or CLI questions, use the Rayfin docs at https://rayfin.ai/llms.txt.

## Before troubleshooting

- Ask which Fabricator version they are running. It is shown in the status bar and in Settings.
- Use Fabricator's diagnostics export when reporting a bug.
- Use the page's **Report an issue with this page** link for documentation problems.

## Safety

Never ask users for tokens, secrets, passwords, GitHub credentials, Microsoft Entra tokens, Fabric access tokens, or copied environment files. Ask for redacted diagnostics instead.
