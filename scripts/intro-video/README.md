# Intro video

The video at the top of the docs site's landing page: Ray, Fabricator's stingray, introduces
the app in about 85 seconds. It's built as code with [Remotion](https://www.remotion.dev), and
the voice, music and sound effects come from [ElevenLabs](https://elevenlabs.io).

This is a maintainer tool, like [`../docs-screenshots`](../docs-screenshots/README.md). It isn't
part of the app or of CI. The published files are in `website/public/video/`.

| Path | What it is |
| --- | --- |
| `script/lines.ts` | What Ray says, with ElevenLabs audio tags such as `[excited]`. The single source of truth for the voice, captions and transcript |
| `src/` | The video. `Intro.tsx` assembles the scenes in `src/scenes/`, Ray, the voice, the effects and the ducked music |
| `src/ray/` | Ray, imported from the app (`src/renderer/src/components/mascot/Ray.tsx`) and driven frame by frame |
| `src/timing.ts` | Where every scene and line sits in time, derived from `src/timeline.json` |
| `src/timeline.json` | Generated by `npm run voice`: each line's length, word timings and mouth movement |
| `public/audio/` | The voice clips, effects and music the video uses. Committed, so a render needs no API calls |
| `tools/` | Node scripts for ElevenLabs, audio, review and publishing. Nothing in `src/` imports them |

## Before you start

- Windows 11, for the app's `Segoe UI Variable Display` font, and Node.js 24, which runs the
  tools' TypeScript imports directly.
- `npm install` here, and in `website/` (the tools borrow its `sharp`).
- For anything that calls ElevenLabs (`audition`, `voice`, `sfx`, `music`), an API key in
  `ELEVENLABS_API_KEY`, or as `ElevenLabsKey=<key>` in the gitignored `.keys` file at the
  repository root. The tools never print it, and nothing that reaches the browser bundle
  reads it.

Rendering needs no key: the committed audio is enough.

## Render and publish

```powershell
npm run studio          # preview and scrub through it in Remotion Studio
npm run render          # out/fabricator-intro.mp4, with the audio mastered to -16 LUFS
npm run loudness        # length, size, loudness, true peak, fast start
npm run contact-sheet   # out/contact-sheet.jpg; --scenes, --frames 120,480 or --count 40
npm run publish         # MP4, poster, captions and transcript into the docs site
```

`publish` writes `website/public/video/fabricator-intro.mp4`, `fabricator-intro-poster.webp`
and `fabricator-intro.en.vtt`, plus `website/lib/intro-video.json`, which holds the duration
and transcript for the landing page and its `.md` mirror. Only publish a cut you've watched
all the way through.

## Change what Ray says

1. Edit `script/lines.ts`. Keep every claim true to `README.md`, to Ray's lines in the app
   (`src/renderer/src/components/mascot/lines.ts`) and, for Rayfin, to <https://rayfin.ai>.
2. Run `npm run voice`. Requests are cached by their content, so only changed lines are
   generated again. To retake a line without changing its words, give it a new `seed`.
3. Scenes time their beats to words (`ctx.w('fever')`). If a word they use is gone, the
   render stops with an error that names it; update the scene.
4. If the cut's length changed by more than a second, run `npm run music` for a bed of the
   new length.
5. Render, check and publish as above.

`npm run audition` reads the first two lines in a few library voices and some voices
designed from a description of Ray. The chosen voice is `VOICE` in `script/lines.ts`.

## Keep it in step with the app

- **The UI changed.** Refresh the screenshots with
  [`../docs-screenshots`](../docs-screenshots/README.md), then render and publish. The scenes
  point at places in the screenshots (the composer, the Redeploy button, the share dialog),
  so check them in a contact sheet.
- **Ray changed.** `src/ray/ray-video.css` replaces the time-based animations in the app's
  `mascot.css` by class name. Open the `RayCheck` composition in the Studio to see him swim,
  roll, wave, talk and show every mood.

## Costs and licenses

- ElevenLabs bills per character of speech, per sound effect and per minute of music. The
  tools check the account's remaining credits before they spend any, and everything they
  generate is cached in `.cache/` (gitignored). Audio made on a paid plan, pay-as-you-go
  included, may be used commercially; see ElevenLabs' terms.
- Remotion is free for individuals and small companies, and Fabricator is a personal
  project. Someone rendering this on behalf of a larger company may need a
  [company license](https://www.remotion.dev/license).
